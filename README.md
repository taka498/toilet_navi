## サービス概要

公共交通機関利用中の急な体調不良が起きた際、 ワンボタンで次の停車駅のトイレへ案内する、 緊急時に特化したナビゲーションWebアプリ

## このサービスへの思い・作りたい理由

通勤や通学などで電車を利用している際、腹痛により途中下車を余儀なくされることが何度もありました。 そのたびに「どこにトイレがあるのか」「間に合うのか」「無駄に遠回りしてしまわないか」といった不安を感じていました。 実際に途中下車してからも、駅構内や周辺でトイレの場所が分からず迷ったり、 やっと見つけても個室が埋まっていて利用できないといった経験もあります。 このような体験から、 体調不良が起きたその瞬間に、考えずに使えるナビがあれば不安を大きく減らせるのではないか と考え、このサービスを企画しました。 また、腹痛に限らず、トイレの利用に制限や不安を抱える方（オストメイトの方、乳幼児連れの方、バリアフリー設備を必要とする方）にも役立つサービスになると思います。

## ユーザー層について 主なターゲット

- 通勤・通学で公共交通機関を利用する人
- 電車やバス移動中に体調不良になりやすい人
- トイレに行けない状況に不安を感じやすい人

## サービスの利用イメージ

1. 通勤・通学中に公共交通機関を利用中に体調不良を感じる
2. スマートフォンでアプリ（ブラウザ）を開き、トップページのボタンを押す
3. 現在地から最も近いトイレが地図上に表示される
4. 途中下車し、ルートを確認。トイレへ迷わずに移動できる

## ユーザーの獲得について

- 開発者自身や身近な通勤・通学者への共有
- 技術ポートフォリオとしての公開
- 実体験ベースの課題解決型サービスとしての紹介

まずは少人数でも実際に使ってもらい、緊急時に迷わず操作できるか、不安を軽減できるかといったサービスの核となる体験を検証していきます。

## サービスの差別化ポイント・推しポイント

- 駅のトイレに特化している点
- ワンボタンでナビを開始できるUX
- トイレの設備情報（バリアフリー・オストメイト）
- 緊急時に必要な情報だけを表示し、迷わせない設計

## 機能候補

MVPリリース時に実装したい機能

- 現在地取得（ブラウザの位置情報）
- 次の停車駅のトイレを 1 件表示
- トイレまでのルート表示
- トイレ詳細情報の表示
  - バリアフリー対応
  - オストメイト対応
  - 乳幼児対応
  - 男女別/共用
  - 和式/洋式

本リリースまでに追加したい機能

- 会員登録・ログイン機能
- トイレ利用後の評価投稿（時間帯・混雑感など）
- 複数トイレの同時表示
- 通勤・通学ルートの登録
- 途中下車後の移動再開支援（次の電車情報など）
