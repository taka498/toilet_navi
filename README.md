## サービス概要

本サービスは電車移動中に腹痛などの不調を感じ、移動は可能だが急いでトイレへ向かう必要がある状況にて、降車前の段階で、降車後に利用できる可能性のある駅のトイレ候補を提示することに特化したナビゲーション Web アプリです。

## このサービスへの思い・作りたい理由

通勤や通学などで電車を利用している際、腹痛により途中下車を余儀なくされることが何度もありました。そのたびに「どこにトイレがあるのか」「間に合うのか」「無駄に遠回りしてしまわないか」といった不安を感じていました。
実際に途中下車してからも、駅構内や周辺でトイレの場所が分からず迷ったり、やっと見つけても個室が埋まっていて利用できないといった経験もあります。
このような体験から、体調不良が起きたその瞬間に、できるだけ考えずに行動を開始できるようなサービスがあれば不安を減らせるのではないか と考え、このサービスを企画しました。
また、腹痛に限らず、トイレの利用に制限や不安を抱える方（オストメイトの方、乳幼児連れの方、バリアフリー設備を必要とする方）にも役立つサービスを目指しています。

## ユーザー層について

主なターゲット

- 通勤・通学で電車を利用する人
- 電車移動中に腹痛になりやすい人
- トイレに行けない状況に不安を感じやすい人

## サービスの利用イメージ

1. 通勤・通学などの電車移動中に腹痛などの不調を感じる
2. スマートフォンでアプリ（ブラウザ）を開き、トップページのボタンを押す
3. 現在地周辺で、降車後に利用できる可能性のある駅トイレ候補が地図上に表示される
4. 利用するトイレを選択し、地図上で位置関係を確認し、進行方向の目安を確認する
5. 降車後、トイレへ向かう

※ MVP では、駅構内の詳細な導線案内までは扱いません。
実際の構内での詳細な位置確認については、降車後に駅の案内表示に従うことを前提とし、
駅構内の導線案内については本リリースで実装する想定です。

## ユーザーの獲得について

- 開発者自身や身近な通勤・通学者への共有
- ポートフォリオとしての公開

まずは少人数でも実際に使ってもらい、緊急時に迷わず操作できるか、不安を軽減できるかといったサービスの核となる体験を検証していきます。

## サービスの差別化ポイント・推しポイント

- 駅のトイレに特化している点
- 検索条件の入力を必要とせず、ワンボタンで駅トイレ候補の提示まで行える UX
- トイレの設備情報（バリアフリー・オストメイトなど）を事前に確認できる
- 緊急時に必要な情報だけを表示し、迷わせない設計

## 機能候補

### MVP リリース時に実装したい機能

- 現在地取得（ブラウザの位置情報）
- 現在地周辺の駅トイレ候補を表示
- トイレまでの大まかなルート表示
- トイレ詳細情報の表示
  - バリアフリー対応
  - オストメイト対応
  - 乳幼児対応
  - 男女別/共用
  - 和式/洋式

※ MVP では、トイレの空き状況や混雑の有無は扱わず、
トイレの場所をすぐに確認し、迷わず到達できることを解決したい課題としています。
駅トイレ候補については、現在地からの距離を基準に複数表示する想定です。

### 本リリースまでに追加したい機能

- Google Maps / Places API を利用した place_id の取得・管理
- Google Map と連携した案内精度の向上
- 管理画面からの駅・トイレ情報の登録・更新
- 会員登録・ログイン機能
- トイレ利用後の評価投稿（時間帯・混雑感など）
- 複数トイレの同時表示
- 通勤・通学ルートの登録
- 途中下車後の移動再開支援（次の電車情報など）
